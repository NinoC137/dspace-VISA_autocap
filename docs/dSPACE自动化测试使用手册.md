# dSPACE / ControlDesk 自动化使用说明

本手册只说明仓库中 MATLAB 和 ControlDesk 辅助代码的使用方式。MATLAB、ControlDesk、实时应用、工程文件和部署目录必须由目标工位提供，具体版本、盘符、账号和工程路径不写入 Git。

## 仓库内组件

- `matlab/DspaceRig.m`：对 ControlDesk 连接、变量读写和录波操作的薄封装；
- `matlab/dspace_selftest.m`：首次联调的只读/低风险检查入口；
- `matlab/exp9_auto_dspace.m`：示例实验脚本；
- `core/`：批测调度、case 选择和结果状态管理。

## 联调顺序

1. 确认目标工位已安装兼容的 MATLAB、dSPACE 和 ControlDesk。
2. 在 ControlDesk 中加载已验证的工程和实时应用。
3. 先运行只读连接检查，确认平台、实验和关键变量可见。
4. 执行 `dspace_selftest` 的非硬件部分，检查变量表、录波器配置和输出目录。
5. 由现场操作者确认 Enable、外部电源和保护设置后，才允许做短时实测。

## 录波与数据

录波配置、信号名、采样窗口和导出格式必须以目标工程实际回读值为准。MF4/MAT 文件、示波器 HDF5、截图和日志属于运行结果，不应加入源码提交。对每次运行保留 case ID、配置摘要、时间戳、状态和校验信息。

## 故障处理

- 找不到变量：检查实时应用和变量描述是否为同一版本，不要直接改脚本中的变量名。
- 无法 Online：先停止其他 ControlDesk 客户端并检查工程状态。
- 录波失败：保留日志和工程状态，确认 `Enable1=0` 后再重试。
- 输出目录异常：更换本地配置中的结果目录，不要把结果写入仓库源码目录。

真实硬件测试前必须由操作者确认设备安全状态；本仓库的离线脚本检查不能替代现场联调。
