# MXO38 采集链路说明

本文件仅说明仓库侧的软件边界。示波器经 USB 接入采集代理，代理负责 VISA/SCPI 通信，PC 侧负责结果校验、HDF5 封装和分析。具体主机、网络、账号、挂载点、驱动版本和仪器身份信息均由部署配置提供。

## 能力

- 建立 VISA 会话并执行身份、状态和错误查询；
- 单次多通道波形采集并写入配置指定的结果目录；
- 分块传输大文件，完成字节数和 SHA-256 校验；
- 采集完成后恢复仪器设置；
- 按需生成屏幕截图或实时观察页面；
- 在 PC 侧继续执行 HDF5、RMS、FFT 和报告分析。

## 使用边界

采集代理与实时观察服务共享仪器锁。批测开始前必须关闭其他控制会话；实时页面默认不常驻，使用后应主动关闭并确认锁已释放。网页数据波形可能临时改变记录长度，关闭后必须回读关键设置。

常用入口由部署环境提供，例如 `scope-capture`、`scope-shot` 和 `scope-web`。不要在公开文档或 Git 中记录 SSH 命令、网络地址、账号、密钥、挂载点或仪器序列号。

## 自检顺序

1. 检查代理进程和仪器电源状态。
2. 执行只读身份查询和错误队列查询。
3. 检查结果目录可写、剩余空间和锁状态。
4. 运行小规模离线或仿真测试。
5. 由现场操作者确认保护条件后，才进行真实采集。

故障时保留日志、清单和未完成文件，先释放锁，再重新执行连接检查。不要通过删除原始测量文件来“修复”传输问题。
