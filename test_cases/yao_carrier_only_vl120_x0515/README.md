# Yao 2023 仅载波移相：SSIC 两交流端口适配

本单元只比较无载波移相 S1 与仅载波移相 S2。原文 DOI：10.1109/TPEL.2023.3284711，式 (15) 的相同参数规则为 180°/N；N=2 时相对载波角为 90°。原文硬件是单相全桥，本测试是对现有三相 SSIC 的角度规则适配，不是原文硬件复现，也不是基于 SSIC 模型重新搜索出的最优角。

| 顺序 | case | 相对载波角 | 用途 |
|---|---|---:|---|
| 1 | YAO_S1_X0515_P000 | 0° | 同工况基线 |
| 2 | YAO_S2_X0515_P090 | 90° | 仅载波移相 |

固定条件：人工设置 HV=240 V、LV=120 V；xi=0.515；ud_ref6=ud_ref7=60，沿用已有测试中这两个参考的定义；50 Hz、10 kHz。各交流端口的基波相位保持现状，不写入相位参考，也不接入 phiOptDeg/phiSearchDeg 闭环。相同参考不等于负载完全相同，必须用记录的 P/Q 检查两个交流端口的实际工况。

每点沿用已部署的 15 s 使能窗口、1 s 等待、10 s 示波器记录，125 kSa/s、每通道 1,250,000 点；两点间断开使能至少 1 s。保留现有八通道参考、dSPACE 记录组及观测变量，仅增加独立 case 和结果目录。禁止截图，不添加缩放、自动调量程、附加视图或探头转接。

## 评价与证据

主评价量是 CH1 的 HVDC 源支路电流 AC RMS；辅助报告 100 Hz 窄带、10/20 kHz 谱线和 5-50 kHz RMS。保持去 DC、窗口和带宽定义一致。CH2 的端口映射未经本次确认，不作为电容电流使用。原文电容 RMS 与本测试源支路 RMS 不可混同；没有直接测量电容支路时，不声称电容电流降低同样比例。

检查：xi、参考幅值、载波角命令读回正确；实际电压和 AC P/Q 可比；稳态段已建立且无削顶；125 kSa/s 和 10 s 几何匹配；manifest/status 的采集、导出与分析分别成功。CH7/CH8 及预测角只作为既有遥测记录，不能单独证明实际 PWM 相位。部署后仅运行离线 Plan，不代表示波器连接、运行镜像和实际接线已验证。

## 启动与停止

安装后在 START_SCOPE_BENCH.cmd 中单独选中“Yao 2023 仅载波移相：0°基线 / 90°（2点）”。默认 run.ps1 为 Plan。Check 会查询真实硬件，Run 会通电采集，两者都必须在具体硬件方案获批后执行。不要与其他批次、手工 SCPI 或截图客户端并行。

运行前由操作者确认电源、负载、探头与现有 VL120 测试一致，Enable1=0，且设备可现场急停。脚本不调整实体电源，不自动下载或启动实时应用。

预期：90°时二阶开关纹波相对0°减小；一阶与总 RMS 的变化由测量决定，不预设总 RMS 必然最优。

可信故障：设置/运行镜像不符导致未施加90°；源电压或负载不符导致过流；示波器参考与探头不符导致单位或量程错误；通信超时导致采集或导出失败。现有执行器在异常和结束时尝试写 Enable1=0 并读回，保存已完成结果。如果控制通信失效，此软件无法保证断能，需操作者立即现场断开使能/急停，再确认电源和负载。示波器导出期间不得强杀进程。

恢复：保持 Enable1=0；检查故障和读回后再决定恢复。运行会留下 xi/ud/phi 的测试值，公共执行器不自动恢复之前参数；需要恢复原设置时先核对运行前参数，禁止在使能状态恢复。软件部署仅新增独立目录和一个目录索引项，回滚脚本会按哈希检查后只删除本项，不覆盖其他测试和历史数据。
