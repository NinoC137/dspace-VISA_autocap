# MXO38 可选控制面板

本目录是可选的本地控制面板，不是批测主入口。它通过 `server.mjs` 调用已配置的 `scope-ctl` 后端，提供状态查看、截图、参数快照和恢复等操作。

## 使用

在本目录启动：

```bash
node server.mjs
```

面板监听地址、远端连接、结果目录和快照目录均由环境变量或本地配置决定，README 不记录默认地址、账号、端口和主机路径。

## 安全边界

- 面板默认用于只读观察；写参数前先保存快照并逐项回读。
- 不要在批测运行期间同时打开面板控制同一台仪器。
- 退出面板后确认连接和锁已释放。
- 快照、截图、日志和连接信息不得提交到 Git。

遇到连接失败时，先关闭面板并使用 `scope_bench/README.md` 的连接检查流程；不要通过删除锁文件或原始数据绕过故障。
